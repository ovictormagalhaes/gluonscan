# gluonscan-evm

EVM on-chain helpers for gluonscan: eth_call over an injected ChainProvider, minimal ABI encode/decode.

Part of [**gluonscan**](https://crates.io/crates/gluonscan) — a stateless multi-chain *read + normalize* engine for DeFi portfolios. Most users depend on the `gluonscan` facade crate, which re-exports this one; depend on `gluonscan-evm` directly only to trim your build to a single slice.
