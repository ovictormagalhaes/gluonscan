# gluonscan-math

Exact-integer DeFi math for gluonscan (Uniswap V3 Q64.96 tick math, etc.). No floats.

Part of [**gluonscan**](https://crates.io/crates/gluonscan) — a stateless multi-chain *read + normalize* engine for DeFi portfolios. Most users depend on the `gluonscan` facade crate, which re-exports this one; depend on `gluonscan-math` directly only to trim your build to a single slice.
