# gluonscan-solana

Solana on-chain helpers for gluonscan: RPC over an injected ChainProvider, base58 pubkeys, program-derived addresses.

Part of [**gluonscan**](https://crates.io/crates/gluonscan) — a stateless multi-chain *read + normalize* engine for DeFi portfolios. Most users depend on the `gluonscan` facade crate, which re-exports this one; depend on `gluonscan-solana` directly only to trim your build to a single slice.
